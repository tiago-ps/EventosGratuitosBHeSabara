# Site v58

## Mudanças

- proporção padrão: cinco eventos para cada livro;
- respeito à ocultação temporária de eventos e livros;
- espaço opcional para um comentário aprovado por livro;
- link opcional para formulário externo de opiniões;
- comentários e formulário desativados por padrão.

## Arquitetura de opiniões

O site público não possui backend e não armazena respostas. O link deve apontar para um formulário institucional privado. Somente comentários já moderados entram em `livros.json`.
